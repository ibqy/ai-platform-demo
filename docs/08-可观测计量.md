# 可观测与计量 — 学习笔记

## 三维指标体系

`PlatformMetrics` 三个维度：租户、接口、模型。每个维度记录请求量、成功率、延迟。

## Token 成本计量

`TokenMeter` 按租户 x 模型记账。用 `AtomicLong costMicro` 定点存储（`cost * 10000`），规避 `AtomicDouble` 不存在的问题。

## 告警规则引擎

`AlertRules` 内置三条规则：错误率 > 20%、token 突增 > 50%、延迟 > 5000ms。每 30 秒检查一次。

## 关键踩坑

- min/max 初始值要用 Long.MAX_VALUE/MIN_VALUE
- 定点存储精度 0.0001 元够用
- 告警阈值应动态调节，硬编码只是起步
