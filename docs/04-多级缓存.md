# 多级缓存 — 学习笔记

## 三级缓存

| 缓存 | Key 设计 | 效果 |
|------|----------|------|
| LLM 回答 | query + modelId + kbVersion | 完全命中直接返回 |
| Embedding | text 原文 | 重复文本免向量化 |
| RAG 检索 | query + kbVersion | 免去检索和 Rerank |

## 缓存失效策略

1. TTL 过期（默认 300 秒）
2. 知识库更新主动清除：`evictByKb(kbVersion)` 遍历删除
3. Embedding 缓存不需要在知识库更新时清除

## 关键踩坑

- 缓存 key 的 query 必须用脱敏后版本
- 不缓存敏感数据在 value 里
- 知识库版本递增后旧缓存自动失效
