# 异步任务 — 学习笔记

## 为什么不能走同步

文档解析、批量向量化需要分钟级处理，HTTP 同步接口不可能等。

## 任务状态机

```
QUEUED → PROCESSING → SUCCEEDED
                    ↘ FAILED → RETRYING → PROCESSING
                                        ↘ DEAD（三次失败）
```

DEAD 状态的设计：失败三次后大概率是任务本身的问题，不依赖重投机制避免故障放大。

## 实现

`ConcurrentLinkedQueue` 模拟 Kafka，`ConcurrentHashMap` 模拟持久化。`TaskConsumer` 用虚拟线程轮询。

## 关键踩坑

- ThreadLocal 在虚拟线程里丢失，租户 ID 要编入 payload
- DEAD 任务需要告警通知人工排查
- 三次重试上限防故障放大
