# AI 网关 — 学习笔记

## 和普通 API 网关的区别

AI 网关不是纯代理，而是一个**编排引擎**：处理 Prompt 预处理、模型选择、模板渲染、结果后处理、成本计量。

## 管道设计：便宜的优先

管道顺序：`限流 → 租户配额 → JWT鉴权 → 注入检测 → PII脱敏 → 缓存 → 路由 → 白名单 → TPM → Prompt渲染 → 模型调用 → 输出过滤 → 计量 → 回写缓存`

**被挡掉的请求不花一个 token 的钱。**

## 三层限流

`GatewayRateLimiter` 全局 1000 QPS + 租户级 100 QPS，每分钟重置。

## 管道编排实现

`AiGatewayService.process()` 用 `AiGatewayRequest/Response` 做上下文，每步读取/写入。失败直接设 errorCode 提前返回。

## 关键踩坑

- 注入检测在 PII 脱敏之前——先检测风险再看原始输入
- 缓存放在脱敏之后——脱敏后的 query 作为 key 确保一致性
- 每个步骤可单独测试
